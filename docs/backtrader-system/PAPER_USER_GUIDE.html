IBKR PAPER 策略验证

从 Python 策略冻结、Backtrader 回测，到选择 PAPER 版本、连接 Gateway、观察订单回报和核对持仓。策略选择和回测不会下单；真实模拟盘动作由操作员在应用里单独触发。

一个共享 PAPER 账户AAPL · BUY 1LMT $400 · DAY · RTHLIVE 禁用
流程总览开始前创建与回测选择版本PAPER 验证怎么看结果故障排查

流程总览

上传 Python→IBKR PAPER 拉取日线→冻结并回测→候选校验→选择部署→单笔 PAPER→回报与持仓对账
1 · 策略和行情先冻结回测使用的源码、订单参数、行情 CSV、交易日程和报告会绑定到一个不可变版本。
2 · 候选需要证据匹配报告必须证明当前授权的固定单笔形状，并带有服务器签发的 IBKR PAPER 行情导入凭证。
3 · 选择部署不下单版本选择需要 PAPER 已停止且订单账本为空；选择后只更新部署绑定并记审计。
4 · PAPER 动作单独触发运行按钮连接 Gateway、对账后派出至多一笔受限订单，随后暂停派单并刷新 IBKR 账户快照。

开始前检查

  • 启动 IB Gateway 或 TWS，并登录同一个 Paper 账户。默认 Gateway 端口为 4002，TWS Paper 端口为 7497。
  • 应用的 IBKR 本地配置必须是 PAPER、只读连接配置且账户/端口与本机 Gateway 一致。
  • 隔离 Python worker 镜像需已配置；否则上传策略可以校验，但无法执行回测。
  • 每位操作员使用具名 operator token；共享 Gateway 账户不等于共享个人授权。管理员按需要发放本次时段内的动作 grants。
当前固定联调配置：AAPL BUY 1 股，限价 $400.00，DAY，只允许常规交易时段；最大名义金额 $400，最多一笔。当前有效窗口为 2026-11-02 14:30–21:00 UTC。窗口外按钮会保持关闭。

操作员凭证

凭证由可信应用主机上的管理员创建并通过团队的安全渠道交给对应人员。不要把 token 粘贴到策略文件、截图或手册中。

在应用中打开设置 → 本地 API 访问，将自己的 operator token 填入服务器 API 密钥并点击保存。页面会刷新；此凭证保存在当前浏览器中。选择 PAPER 策略和控制运行时，即使访问 localhost 也需要具名 token。

管理员可在项目根目录运行以下命令创建操作员 token：

uv run --project agent python -m src.execution.paper_operator_tokens issue --subject partner-name

Grant 需绑定操作员、共享 DU Paper 账户、动作名称和有效时间。start、activate、stop 等动作分别授权。现行单笔按钮会按运行需要校验对应授权。

创建、冻结并回测策略

  1. 打开应用的 Execution 页面，在 Python 上传区域下载单笔 PAPER 联调示例。打开文件，将其中的 2026-10-30 改为本次单日评估日期，然后保存并上传。通用回调模板默认不发订单，需自行编写规则。策略入口是 on_event(event, state)；上传代码在隔离 worker 中按已完成 bar 执行。
  2. 当前部署包络保持：策略 ID 自选；标的和 instrument 都填 AAPL；股数填 1；订单类型选 LIMIT · DAY；限价填 400.00。
  3. 设置暖机和评估日期。固定单笔候选的评估区间必须只有一个 XNYS 交易日，且该日必须是执行时 IBKR 返回的最新完整交易日；数据需包含完整 RTH 日线和精确交易日程。当前 2026-11-02 的常规时段窗口内，预期评估日为 2026-10-30；实际仍以 Gateway 返回的数据为准。
  4. 已有已选 PAPER 报告时，可点击使用当前 PAPER 回测日期，填入报告评估日和其前一个交易日。该按钮使用的是已选报告日期；如果最新完整交易日已变化，请手动调整并重新拉取日线。
  5. 点击 Fetch daily bars from IBKR，使用 IBKR PAPER 和当前本机端口。页面会自动填入 CSV 与交易时段 JSON。成功后会显示服务器验证的 PAPER 来源凭证。
  6. 上传 Python 文件，点击 Validate and review upload。确认卡检查来源凭证、标的、数量、订单类型、限价、日期、bar 数和各项 SHA-256。
  7. 确认无误后点击 Confirm and run Backtrader。这一步只运行离线回测，不连接 Gateway、不发订单。成功结果会保存一份 immutable strategy version 和可复核报告。
不要手工改来源标签来绕过校验。从 CSV 上传或手写 provider 标签可以用于普通离线研究，但不会获得 PAPER 来源凭证。服务器的一次性凭证绑定当次 PAPER 拉取的精确 CSV 和 XNYS 交易日程；修改行情后需重新拉取。

策略要满足的候选条件

  • Python upload、AAPL、long-only 显式 1 股、完整日线、XNYS regular session。
  • 策略在评估日产生且只产生一笔 BUY 1、LIMIT $400、DAY、RTH-only 订单。
  • 离线回测到数据末尾仍未成交；报告中应为未成交订单且没有 fill。
  • Backtrader 报告回放完整性 verified，报告、冻结版本和服务器验证的 PAPER 行情摘要彼此匹配。

选择 PAPER 版本

  1. 在 Execution 页的 Frozen Backtest Versions 查看候选和阻止原因。
  2. 只有标注为当前 PAPER 流程兼容的版本才会显示可选按钮。选中 Use for this PAPER check。
  3. 服务端要求有具名操作员、运行时 STOPPED、单笔订单账本为空且没有正在执行的联调动作。
  4. 选择成功后，应用绑定冻结版本、复制并复核回测报告、重建本地组合，并在用户目录的部署审计文件中记录操作员、版本和报告摘要。
选择版本没有券商副作用。它不会启动 Gateway、打开派单闸门或提交订单。可先确认 PAPER 状态显示所选版本，再进行下一步。

当前 SMA MARKET/按资金比例模板不符合这组固定订单约束，目录会显示阻止原因；它不会被静默改写成一股限价单。

在 PAPER 做单笔验证

  1. 确认 Gateway/TWS 已登录 Paper 账户，且 PAPER integration status 的报告证明为 verified、运行时间在有效窗口内。
  2. 确认订单参数仍为 AAPL BUY 1、LMT $400、DAY、RTH-only。当前配置不会按策略自由扩大数量或金额。
  3. 在 Execution 页点击 Run the one-shot PAPER order。这是唯一会发起本轮模拟单的显式操作。
  4. 应用读取 IBKR 最新完整 bar，启动托管运行时并先做账户、持仓、开放委托对账；通过后只送出这一笔订单。
  5. 动作结束后应用关闭派单闸门、转为暂停状态并请求新的券商账户快照。查看订单 ACK/拒绝、成交回报和快照中的实际持仓。
收到 ACK 不等于成交。限价单可能被接受但没有成交；以成交回报和后续 IBKR position snapshot 为准。应用不会用本地 fill 数量猜测账户持仓。
请勿把此流程切换到 LIVE。当前流程只使用本地 PAPER profile 和受限单笔授权；LIVE 下单能力保持禁用。

结果核验与记录

观察到的状态含义下一步
ACK / SubmittedIBKR 已接收或挂出委托，不代表成交。查看 executions 与新鲜持仓快照。
Rejected券商拒单；购买力、合约或账户条件可能不满足。保留拒绝回报和错误码；不要通过放宽上限重试。
部分成交部分股数已成交，剩余量仍可能活动或被取消。对照累计成交、剩余股数、开放委托和对账后的持仓。
Filled订单已完全成交。核对成交明细、手续费和 broker position snapshot。
Reconciliation failed券商快照不足以确认账户最终状态。保留暂停状态；先通过 PAPER recovery/reconciliation 恢复，不要再次下单。

验收时记录运行时间、策略版本 ID、Backtrader 报告摘要、订单状态、IBKR execution IDs、成交股数/价格/费用、对账时间和实际持仓变化。不要记录账户凭证或 operator token。

活动列表会显示券商订单号和已有成交的 execution ID，方便与 Gateway 核对。券商订单号的出现本身不证明 IBKR 已接受委托；查看订单状态和回报。若遭拒绝，具体错误码与原因请同时查看 Gateway。

停止运行后，页面仍可查看本机保存的订单与成交历史；此时当前券商持仓显示为未知。重新启动并完成对账后，才能查看新的券商持仓快照。

如果订单仍处于已接收或部分成交状态且需要撤销，在运行时仍持有连接的情况下，点击该订单旁的撤销这笔 PAPER 委托。这需要该操作员有当前 PAPER 账户的 cancel 授权。请求发送后仍需等待并查看券商撤单回报；已成交部分不会被撤销。

常见问题

现象原因和处理
没有 PAPER 来源凭证用 IBKR PAPER 按钮重新获取日线；确认选择的是 PAPER profile/端口，再重新预览。手动上传或改 provider 标签不算来源证明。
策略不在可部署候选中展开阻止原因。常见情况是 instrument 不等于 AAPL、数量不是 1、订单不是 LIMIT $400、评估日期多于一天或没有恰好一笔未成交 BUY。
执行时提示最新完整 bar 与冻结信号日不一致重新从 PAPER 拉取数据，将单日评估日期设为 Gateway 最新完整交易日，重新预览、回测并选择新冻结版本。执行前请确认单笔账本仍允许选择版本。
Gateway 无法连接确认 Gateway 已登录 Paper 账户、本地 API 已启用、端口与应用配置一致；不要切换到 LIVE 端口。
Python worker 未配置或不可用确认应用主机的 Docker 上下文 colima-vibe-execution 已运行，并在应用配置中设置 VIBE_PYTHON_WORKER_IMAGE 为本机已构建的镜像 ID。构建和检查命令见项目 agent/src/execution/strategy_worker_image/README.md；配置后重启 API。
按钮显示窗口未开放当前写入授权只在 2026-11-02 14:30–21:00 UTC 生效；不在窗口内提交。新窗口需由授权负责人重新配置。
没有权限或 grant expired请管理员检查具名 operator token 和对应 PAPER action grant 的账户、动作及有效期。
订单已接受但无 fill限价或市场状态可能使委托保持 open；查看 IBKR 状态并以 broker snapshot 核对，不能把未成交当成成功闭环。
对应操作说明和授权命令见 PAPER_OPERATORS.md。本手册记录当前固定的一笔 AAPL PAPER 验证包络；它不是通用风险授权。报告数据的历史时点可用性和 IBKR 复权语义仍需结合数据说明判断。
