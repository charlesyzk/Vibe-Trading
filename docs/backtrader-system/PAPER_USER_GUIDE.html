本手册随安装包提供，也可作为独立 HTML 文件在浏览器打开。页面上的 Execution 是策略与模拟盘操作页面；PAPER 表示模拟账户。

开始前

请注意：Windows 的安装、启动和同版本重装已经测试；实际 Gateway 模拟账户连接以及真实模拟订单回报仍需在使用环境中验证。请持续查看会话和订单状态。
  1. 双击 Windows 安装程序，按提示选择安装位置并完成安装，然后从桌面或开始菜单打开应用。IB Gateway 或 TWS 需要单独安装；启动后选择并登录所需的 Paper 模拟账户。
  2. 在 Gateway/TWS 的 API 设置中启用 Socket Clients；如需后续提交或撤销模拟委托，还需关闭 Gateway 的 Read-Only API 选项。保持登录的是 Paper 模拟账户。打开应用的 Execution 页面，等待自动检查，或点击检查 PAPER Gateway 连接。成功后页面显示已核验的模拟账户。只读检查不表示策略已启动。
  3. 如果同时发现多个账户或多个本机 PAPER 端点，先只保留需要使用的一个，再重试。桌面版通用草稿自动使用本机操作员配置，不需要手工复制 token。

Windows 验证安装包内置应用运行环境和隔离策略 worker，无需自行安装 Python 或 Docker；已在 Windows 测试干净安装、启动和同版本重装。真实 Gateway 连接及完整伙伴流程仍待验收。IB Gateway 需要另行安装和登录。自动识别使用 Gateway 或 TWS 的默认 PAPER API 设置；如果改过默认连接设置，请在 Gateway/TWS 恢复默认后重试。

创建、冻结并回测

  1. 打开 Execution，找到运行隔离的 Python 上传策略。在“策略 .py 文件”选择策略文件；需要示例格式时先点击下载 Python 回调模板。
  2. 填写“IBKR 代码”（例如 AAPL）、“明确整股数量”（例如 2）、“回测订单类型”。选择 LIMIT 时还要填写“限价（USD）”；MARKET 是市价单。按策略要求填写其他参数，检查日期、初始现金和成本假设。
  3. 登录模拟账户后点击从 IBKR 获取日线，等待显示日线已载入和服务端 PAPER 来源凭证。应用会同时准备所需交易日程；仅手工填写来源标签或上传文件，不会自动取得可用于 PAPER 部署的来源凭证。
  4. 点击校验并预览上传内容，仔细核对标的、股数、订单类型、限价、日期与数据。需要更改时点击修改上传内容；无误后点击确认并运行 Backtrader。
  5. 等待“已保存 Python Backtrader 报告”，查看报告。回测不会提交券商订单；保存的策略版本、参数、行情和报告会绑定在一起。修改标的、数量或订单规则后，请重新获取对应行情并回测。

并非所有标的、数量或订单都可使用。合约、行情权限、交易时段、账户事实和风险上限不满足时，页面或服务端会给出阻止原因。旧的 AAPL BUY 1、$400 限价单是单独的固定联调入口，不是通用草稿的标的限制。

核对草稿并启动

  1. 在已冻结的回测版本找到刚才的报告，选择买入或卖出，点击核对订单证据。证据匹配后展开核对开仓时段和风险上限。可点击使用当前或下一个交易时段自动填入时段，再自行确认；手工填写时间须带时区。最多可选择 90 天，起止时间须在美股常规交易时段内。限价、市价等规则需与冻结策略一致。
  2. 点击保存 PAPER 草稿，确认无误后点击部署已保存的 PAPER 草稿。保存和部署不会下单。部署时会重放历史数据以准备策略状态，数据较多可能需要等待。
  3. 在允许的开仓时段点击启动 PAPER 并处理初始信号。应用会检查账户、订单和最新完整日线；初始信号投递成功不代表券商已接受订单或订单已成交。
  4. 若所选窗口覆盖多个交易日，保持应用和 Gateway 运行；应用在后续常规交易时段检查上一交易日的完整日线。缺失、跳过交易日或行情不匹配时会暂停，需先核对并重新准备。应用重启不会自动恢复策略运行。

查看订单、撤单和停止

在 Execution 页查看 PAPER 会话状态、订单和成交历史。订单和成交历史显示本机记录。ACK 或 Submitted 表示券商已接收或挂出委托，不等于成交；部分成交时仍需核对剩余数量、成交记录和券商持仓。

对本应用持有的活动委托，可点击撤销这笔 PAPER 委托。开仓时段结束不会自动取消委托，也不会因此禁止对符合条件的已有订单请求撤单。请求发出后应等待券商确认；已成交部分不会撤销。结果未知或拒绝时先在 Gateway 核对，不要假定已撤销。

停止会话会停止新增订单，但不会自动撤销已有委托。暂停后的草稿不能直接重新开启派单：请先停止会话、核对订单并准备新的回测后再启动。若会话已停止，可按页面提示恢复原保存部署并重新连接，以暂停状态对账和管理符合条件的活动订单。恢复依赖原草稿、本机配置及匹配的订单记录；存在发送结果未决或跨部署订单时会拒绝恢复。

真实 Gateway 的撤单回报和恢复仍待验收。真实 PAPER 订单的 ACK、成交及对账由伙伴后续验证；目前没有以真实订单验证这些结果。
