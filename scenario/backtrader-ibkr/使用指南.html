操作流程 · 两种入口共用后半段

从登录到报告，按顺序走。

按钮名称可能随页面版本略有变化。以页面实际显示为准；拿不准的高级参数先保留默认值。

01

打开 IBKR 模拟环境，并进入策略执行

启动 IBKR Gateway 或 TWS，登录 PAPER 模拟账户 并保持运行。打开 Vibe-Trading，在左侧导航选择 策略执行 / Execution。首次使用先在连接中心检查 IBKR 连接。

连接端口Gateway 通常为 4002；TWS 通常为 7497。不要把 LIVE 端口当作 PAPER。
02

选择策略入口，填写标的和日期

文字入口填写买卖规则；Python 入口上传已准备的 .py 文件。两种入口都要选择 IBKR 本地连接、PAPER 配置，以及当前登录所用的 Gateway/TWS 端口。首次可以先保留 AAPL 示例。

Python 入口需要设置暖机日期和评估日期；暖机日期应早于评估日期。页面可用 IBKR 日线自动填入行情和交易日历。

不熟悉的设置先保留页面预填的费用、滑点和行情字段，不要凭猜测修改。
03

先预览，再检查关键信息

文字入口选择 预览策略规则；Python 入口先选择 从 IBKR 获取日线，上传策略后选择 校验并预览上传内容。阅读页面预览，确认规则、标的、行情来源、日期范围和数据数量符合预期。

如果页面提示策略不受支持、数据不足或日期不完整，按提示调整规则或日期后重新预览。

这是你的检查点信息不对就先返回修改；确认前不会运行这次回测。
04

确认运行离线回测

检查无误后，点击页面的确认按钮：文字入口通常显示 确认并运行离线回测；Python 入口通常显示 确认并运行 Backtrader。系统使用 IBKR 历史日线，由 Backtrader 计算这次策略回测。

本流程不发订单这是历史数据回测，不会向 IBKR 提交买卖订单。
05

打开报告，理解结果边界

在结果区域查看收益、费用等回测指标及报告完整性状态。报告链接会打开已保存的运行详情，方便之后复核。

报告完整性通过说明报告与系统回放校验一致；它不能证明策略未来盈利，也不代表行情复权、历史可用时点或数据许可已认证。

可复核 ≠ 有收益保证历史表现用于研究，不是未来表现承诺。

现在可以做什么

使用 IBKR 历史日线作为数据源，在 Vibe-Trading 中运行 Backtrader 离线回测；可以使用受支持的文字策略入口，也可以提交已准备好的 Python 策略。

哪些事情另行处理

真实交易仍暂缓。账户持仓查询、订单预演、PAPER 下单和实时行情是其他流程；这份指南中的回测不会提交订单。AAPL 实时行情还可能受 IBKR 行情订阅限制。

遇到问题时

常见问题

点开问题查看下一步。联系维护人员时，提供页面错误文字即可；不要发送密码或验证码。

IBKR 连接失败，先检查什么？

确认 Gateway 或 TWS 正在运行并已登录 PAPER；再核对连接配置和端口是否匹配：Gateway 通常为 4002，TWS 通常为 7497。若仍失败，把页面显示的错误文字发给维护人员。

为什么没有获取到行情？

先检查股票代码和日期范围，尝试缩短日期区间。不同标的和历史时段的可用数据可能不同；部分行情也受 IBKR 市场数据权限影响。

为什么文字策略提示不支持？

文字入口目前支持双均线交叉或明确周期的 RSI 阈值规则。用清楚的买入、卖出条件描述，暂时去掉其他过滤条件；或者请维护人员准备 Python 策略文件。

上传 Python 后无法预览或运行怎么办？

先确认上传的是按页面模板接口准备的 .py 策略文件。若提示 worker 未配置、日历或数据有误，请把页面错误文字发给维护人员。日常使用者不需要自行配置 Docker 或环境变量。

这次回测会在 IBKR 里买卖吗？

不会。这份指南覆盖的是读取历史日线并离线运行 Backtrader。账户查询、订单预演及任何下单操作都不在这里的流程里；真实交易尚未开放。
